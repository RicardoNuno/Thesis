# Sources

- [`references.bib`](references.bib): single BibTeX file, exported from Zotero (Better BibTeX, auto-export). The thesis uses this file directly.
- [`reading-list.md`](reading-list.md): everything found, with reading status.
- [`notes/`](notes/): one note per paper, named after its bibkey, in a folder per reading-list section (e.g. `notes/dependency-and-effects/`). Copy [`notes/_template.md`](notes/_template.md).

PDFs are **not** committed (copyright + size); keep them in Zotero.
